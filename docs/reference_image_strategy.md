# 参考图策略说明

本文档专门说明多参考图任务里，如何定义每张参考图的职责，避免“都参考一点”导致模型权重混乱。

## 当前工程里的常见角色分工

### `reference_01_main`

通常负责：

- 主人物脸型
- 五官比例
- 发型和气质
- 最重要的主体识别

适用原则：

- 如果只有一张图必须被严格保住，通常就是它

### `reference_02_detail`

通常负责：

- 服装结构
- 身体模板
- 局部造型
- 材质层次

适用原则：

- 当主参考图只适合锁脸，不适合锁身体或衣服时，用它补结构信息

### `reference_02_style_right`

通常负责：

- 正确模板
- 正确牌型
- 正确姿势
- 正确构图基准

适用原则：

- 用来告诉模型“应该长这样”

### `reference_03_style_wrong`

通常负责：

- 只提供某个局部语义
- 或者作为反例对照

当前任务里常见用法：

- 只借用 `✗` 的颜色和符号语义
- 不继承整个人物和模板

适用原则：

- 明确告诉模型“只参考这里，不要整套照搬”

## 在 `task_prompt.md` 里怎么写清楚

推荐写法：

- 把每张参考图的责任单独点名
- 明确“谁负责脸，谁负责身体，谁只负责局部语义”
- 明确“最终主体更接近哪一张”

不推荐写法：

- “综合参考图 1、2、3”

因为这会让模型无法判断优先级。

## 什么时候需要“反例语义”

适合使用反例语义的情况：

- 你只想借一个颜色或符号
- 你想告诉模型某种模板只是“局部参考”
- 你担心模型会被错误示例整套带偏

写法重点：

- 明确说“仅提供某个局部语义”
- 明确说“最终主体不要接近这张图的人物”

## 多参考图任务的最低表达要求

一个合格的多参考图任务，至少要写清：

1. 哪张图负责主体识别
2. 哪张图负责姿态或模板
3. 哪张图只负责局部符号或细节
4. 最终结果整体更接近哪张图
5. 哪些错误继承必须避免

## 常见错误

- 所有参考图都写成“参考”
- 只列文件名，不写职责
- 反例图没有被明确降权
- 主参考图和模板参考图优先级相互打架
- 在 `关键细节` 里写了局部要求，但 `主体` 没交代哪张图负责什么
