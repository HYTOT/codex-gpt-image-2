# 任务提示词写作指南

本文档说明如何把原始中文需求整理成当前工程要求的六段式 `task_prompt.md`。

## 基本规则

- 固定 6 个标题：`场景 / 主体 / 关键细节 / 用途 / 约束 / 特别要求`
- 每个标题下 3 到 5 条 `-`
- 每条都写成完整中文提示句
- 长度适中，信息密度高，不写成长篇散文
- 每个任务默认视为独立新任务，不写跨任务修订语气

## 六个分段分别写什么

### `场景`

优先承载：

- 画面类型与比例
- 使用场景或最终成片形态
- 整体阅读顺序与第一视觉重点

不要只写：

- “生成一张海报”

应拆开写：

- 先读成什么
- 画幅是什么
- 画面节奏和主次如何组织

### `主体`

优先承载：

- 主要人物或物体是谁
- 参考图之间谁负责脸、谁负责身体、谁负责语义
- 主体识别点与不可丢失的关键特征

### `关键细节`

优先承载：

- 文案内容
- 小动作
- 材质与风格细节
- 排版、牌面、道具、地标等中层信息

### `用途`

优先承载：

- 最终图要拿来做什么
- 成片在传播、聊天、收藏、播放器背景等场景里的核心要求
- 缩略图和大图分别要满足什么

### `约束`

优先承载：

- 明确要避免的错误方向
- 已知高频翻车点
- 模型容易跑偏的风格或结构问题

### `特别要求`

优先承载：

- 优先级
- 特殊白名单/黑名单
- 局部必须满足的强约束

## 什么叫“长度适中”

推荐写法：

- 一条只解决一个维度
- 允许一句话里包含 2 到 3 个紧密相关条件
- 不把构图、主体、文字、约束、优先级全部塞进同一条

不推荐写法：

- 一条里同时塞入角色来源、动作、文案、颜色、禁用项、优先级和验收目标

判断标准：

- 读完单条后，能明确知道这条是在约束“哪一类事”

## 从单条压缩版到 3 条展开版

### 示例 1：人物海报

压缩版思路：

- “生成一张适合传播的人物海报，人物高保真，标题是张含韵，带副文案和署名。”

展开版思路：

- `场景`：海报类型、比例、缩略图抓手
- `主体`：人物脸、服装、气质、可调但不可改的范围
- `关键细节`：主标题、副文案、署名和符号语言分别拆开

### 示例 2：多参考图贴图

压缩版思路：

- “用参考图 1 的脸和参考图 2 的身体做 16 格举牌贴图，牌面固定，保持统一。”

展开版思路：

- `主体`：脸、身体、反例语义分别由哪张图负责
- `关键细节`：牌面列表、模板统一性、手部结构分成独立条目
- `特别要求`：优先级、中文禁用格、单行显示等拆开

### 示例 3：城市信息图

压缩版思路：

- “做广州美食地图，放标题、12 个点位、地标和图例，风格像旅行手账。”

展开版思路：

- `场景`：地图整体气质、视角、河流组织作用
- `主体`：标题系统与固定点位列表
- `关键细节`：推荐语、粤语点缀、地标、图例分开写

## 高质量自检清单

提交前至少自问：

1. 每段是不是 3 到 5 条
2. 每条是不是只承载一个主要维度
3. 有没有把优先级单独写出来
4. 有没有把已知高频翻车点放进 `约束`
5. 多参考图任务里，有没有明确每张图负责什么
6. 文字要求是不是写得足够具体，而不是笼统写“字要清楚”
