# GPT Image 2 歌词播放器背景图生成任务｜default_v1

请根据以下要求，基于输入人物参考图与歌词内容，生成一张适合作为歌词播放器背景使用的高质量横版图片。

## 任务目标

- 画面用途固定为歌词播放器背景图
- 画幅固定为 16:9 横版
- 具体分辨率沿用当前任务配置，不在本模板中单独指定
- 输出必须是纯画面成片，不是海报、封面或宣传图
- 目标是兼顾美感、空间秩序、视觉层次与后续歌词叠加的留白可用性

## 人物主体要求

- 将输入图片中的人物转换为高完成度 Q 版形象
- 比例采用明显的大头萌脸 + 小身体设计
- 头部圆润饱满，五官灵动可爱，表情自然有神
- 可爱但不低幼，不粗糙，不廉价卡通化
- 高度还原参考人物的核心特征，包括发型轮廓与发色、服装款式与主色关系、配饰与装饰细节、材质印象、整体气质、神态与辨识感
- 最终效果要做到一眼能认出是参考人物的 Q 版化身，而不是普通陌生角色
- 不要生成普通写实人像，必须明确是高质量 Q 版人物
- 不要过度夸张变形到失去参考人物特征

## 构图与留白要求

- 人物位于画面左侧 1/3 区域
- 人物整体高度约占画布总高 3/4
- 以完整度较高的 Q 版半身偏全身表现为主，可到膝部以上
- 如果未额外指定动作，请默认参考输入图原有姿态与动作趋势
- 如有额外动作要求，请按以下内容调整：{{action_override}}
- 人物与背景之间要有自然的光影衔接、空间融合与空气透视
- 边缘过渡必须流畅，不要像贴纸、抠图或悬浮层一样生硬分离
- 画面中间约 1/3 区域必须保持明确留白意识，方便后期叠加歌词
- 中间区域不要堆放复杂主体、不要安排过强视觉中心、不要使用高对比杂乱纹理
- 留白区域可以保留轻量氛围内容，例如柔和光晕、浅景深、轻雾、空气感颗粒、柔和渐变、远景虚化
- 版面结构必须形成：左侧 Q 版人物明确可爱 / 中间区域舒适留白 / 右侧背景延展歌词意境

## 背景生成逻辑

不要机械照搬参考图环境。请先分析歌词内容的意境、情绪、时间感、空间感与叙事氛围，再据此生成背景场景。

创作要求：

- 自动提炼歌词中的情绪、时间、空间、元素与整体气质
- 情绪可包含：温柔、明亮、治愈、思念、浪漫、释然、热烈、自由、成长、梦幻等
- 时间可包含：清晨、午后、黄昏、夜晚、雨后、晴日、月色等
- 空间可包含：室内、窗边、庭院、街角、海边、山野、湖畔、花园、远景、想象空间等
- 元素可包含：风、光、云、花、水、星点、雾、雨丝、飞鸟、叶片、波纹、光尘等
- 气质可包含：轻盈、清透、温暖、安静、辽阔、柔和、诗意、空灵等
- 只提炼核心氛围和少量代表性元素融合，不要逐句插图式翻译歌词，不要把所有意象堆满画面
- 整体定位为介于现实与梦境之间的抒情空间
- 可以有现实空间基础，如窗边、房间、走廊、街道、山野、海边、湖畔、花园、庭院、黄昏天光、夜色微光、云层远景、自然风景
- 场景需要经过歌词情绪的柔化与艺术化处理，形成真实可感且略带幻想与诗意的梦境氛围
- 不过于写实生活照，不要赛博科幻风过重，也不要纯抽象概念空间

## 画面风格要求

- 整体风格根据歌词意境自动匹配，但必须保持明亮通透、有光感与镜头感、具有电影质感
- 色彩统一、层次清楚、高记忆度、精致细腻、完成度高
- 梦幻但不廉价，可爱但不幼稚，唯美但不浮夸
- 风格倾向接近高质量动画电影场景 + 精致 Q 版角色插画
- 允许适度加入柔和体积光、空气透视、轻微漂浮元素、微风感动态线索、环境光尘、星点、薄雾、水面反光、花瓣、云层层次等
- 所有效果都必须服务于歌词氛围，不要堆砌炫技特效

## 与歌词联动规则

- 可根据歌词意境，为人物加入少量自然呼应的互动细节
- 例如视线方向、身体朝向、轻微表情变化、手部动作或少量贴合歌词的氛围配件
- 所有联动都必须克制、自然、服务整体，不能喧宾夺主
- 核心仍然是左侧高辨识度 Q 版人物 + 中间区域干净留白 + 与歌词一致的高质感背景氛围
